    Active Object (Quantum Leaps QHsm / QActive)
    
    
    Each PlanItem / StageGate is an active object: it owns a private event queue and processes events run-to-completion — no shared mutable state between objects, only asynchronous signals (SIG_*). The TypeScript engine interprets the .qm XML directly instead of generating C/C++.
    
    
    code: src/hsm/qmXmlParser.ts, models/*.qm · invariant: I-HSM-ONLY
    

  
    Hierarchical state machine & Q_SUPER inheritance
    
    
    States form a tree (/top/Operational/Executing/InProgress). When a leaf doesn't handle a signal, the engine walks up the superstate chain (Q_SUPER in QP) until a state with a matching <tran> is found — e.g. SIG_BLOCK from InProgress is handled by /top/Operational.
    
    
    code: resolveSignalWithQSuper in src/hsm/lcaEngine.ts
    

  
    LCA transition: EXIT → ACTION → ENTRY
    
    
    For source S and target T, the lowest common ancestor is computed; states below it are exited bottom-up, the transition action runs once, then states down to T are entered top-down (plus composite initial drill-down). The trace is fully deterministic, e.g. EXIT(InProgress: freeze_working_tree_diff();).
    
    
    code: executeLcaTransition in src/hsm/lcaEngine.ts · SPEC-001 §3.2
    

  
    Relative targets ../../2 + target_path validation
    
    
    In .qm XML, transitions address targets by tree coordinates: each .. walks one level up, each integer picks the n-th child (0-indexed). If target_path is present, the parser checks the resolved coordinate against it at load time — broken statechart edits fail fast.
    
    
    code: resolveQmRelativeTarget in src/hsm/qmXmlParser.ts · SPEC-001 §3.1
    

  
    Monotonic YAML rule lattice
    
    
    Tiers GLOBAL ≼ LEVEL ≼ ITEM may only tighten: minimums take the max, ceilings the min, required predicates only union, role whitelists only shrink (subset). Any relaxation throws MonotonicityViolationError at compile time. Try lowering min_test_coverage_pct in tier 3 above and hit “compile lattice”.
    
    
    code: compileMonotonicYamlChain in src/rules/yamlLatticeCompiler.ts · invariant: I-MONOTONIC-YAML
    

  
    may() — three-gate capability check
    
    
    Every mutating verb (MCP tool, git hook) must pass: Gate A the intent's role whitelist resolved through the HSM superstate chain from the active state; Gate B the session's [:ASSIGNED_TO] roles intersect that whitelist; Gate C live telemetry satisfies the compiled monotonic guards (coverage floor, blocker ceiling, clean-worktree/CI predicates).
    
    
    code: evaluateMayGatekeeper in src/mcp/orchestrator.ts · invariant: I-MAY-GATE
    

  
    Conserved time-linear lineage (hash-chained events)
    
    
    Every mutation appends an immutable TemporalEvent to a singly-linked chain ([:PREV_EVENT], head at [:HEAD_EVENT]) inside the same ACID transaction. Each event stores chainHash = SHA256(prevHash :: eventId :: … :: trace), so any out-of-band edit breaks the chain — try “tamper event #1” then “lineage.verify”.
    
    
    code: appendConservedTemporalMutation / verifyTemporalLineageIntegrity in src/graph/lineageWriter.ts · invariant: I-TEMPORAL-CHAIN
    

  
    PRINCE2 rolling wave & management by exception
    
    
    Levels (management stages) sit behind StageGates. Only the ACTIVE level (N) and lookahead (N+1) may decompose into tasks; N+2 stays FUZZY_LOCKED. The steward audits time/token/scope/quality tolerances; breaches escalate via SIG_TOLERANCE_BREACH (caught by /top/GateGovernance via Q_SUPER), and PM sign-off atomically shifts the wave: N→COMPLETED, N+1→ACTIVE, N+2→ROLLING_LOOKAHEAD.
    
    
    code: src/steward/stewardAuditEngine.ts · invariant: I-ROLLING-WAVE
    

  
    Markdown is a projection, never source of truth
    
    
    .md files are rendered on demand from the Neo4j graph (frontmatter carries head_lineage_sha256). Editing the markdown does nothing; mutate via MCP verbs and re-project.
    
    
    code: renderVirtualMarkdownProjection in src/graph/mdProjector.ts · invariant: I-MD-PROJECTION
